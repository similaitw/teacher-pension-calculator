# 正式審定案例驗證資料

本目錄只放已去識別化、可供專案比對的正式審定或人事試算案例。正式發布至少需要以下三類各一份：

- `pure-fund`：無舊制的純基金制案例。
- `mixed`：同時含退撫新制前、後年資的案例。
- `leave-or-combined`：含留職停薪或可併計年資的案例；建議用 `segments` 逐段記錄。

複製對應的 `*.example.json`，移除檔名中的 `.example`，再填入正式資料。範例檔不會被驗證器讀取，也不得視為正式案例。

去識別化時請移除姓名、身分證字號、出生年月日、服務機關、職稱、地址、案號與可回推個人的備註；保留制度類別、核定年資月數、計算薪額、核定一次退休金、核定月退休金與扣減總額。`source.document` 只寫無個資的來源代稱，並人工確認後將 `source.anonymized` 設為 `true`。

年資區段使用民國年月的「月份索引」：`民國年 × 12 + 月 - 1`，區間採起月包含、迄月不包含。若已有主管機關核定舊制月數，可用 `legacyInput: {"mode":"certifiedMonths","certifiedMonths":120}` 覆寫逐段推算的舊制月數。

執行：

```powershell
npm run test:official
```

每個案例會逐欄輸出預期值、實算值、差額及容許誤差。三種類別未齊、欄位缺漏、未確認匿名化或任一欄超出誤差，都會以非零狀態結束並阻擋正式發布。
